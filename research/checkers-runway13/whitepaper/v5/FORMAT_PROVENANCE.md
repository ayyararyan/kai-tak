# Preserved academic format

V5 inherits V4's RFS.cls, rfs.bst, crop.sty and crop.cfg byte-for-byte. The working-paper style changes edition metadata only. Page size is517.38×779.30PDF points (182.52×274.92mm), text width373.2TeX points, body Times12TeX points with14.4-point baseline. NewTX mathematics and the original heading/caption/reference conventions remain. No magazine columns, display-font system or cover redesign replaces the academic format.

Figures use locally licensed Arial, restrained ink/slate/copper/sage/blue colours, vector strokes and explicitly scoped raster source imagery. Final PDFs embed font subsets. Installable proprietary font files are excluded. Figures are7.1-inch editable masters, scaled to the manuscript text block; supplementary technical plots use the same lettering hierarchy. Output inspection checks actual page size and embedded Times/NewTX fonts independently of TeX source declarations.

Exact font/table/page receipts: qa/fonts.txt and qa/document_checks.json. The final visual inspection is a separate recorded acceptance step, not inferred from the font checks. Different font or TeX versions may change pagination; the tested local toolchain and clean rebuild are documented in REPRODUCIBILITY.md.
