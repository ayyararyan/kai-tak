## Already authorized locally

- [x] Audit before archive structure changes; preserve original paths/evidence.
- [x] Verify three existing releases and actual remote asset bytes.
- [x] Write nine collection catalogues, schemas, rights and provenance records.
- [x] Build permitted-data candidates and test clean local download/restoration.

## Required before publication

- [ ] Reconcile remaining per-file provenance/authorship and public-v1 frozen-manifest discrepancies; issue an explicit correction record, not silent historical edits.
- [ ] Review exact source-specific inclusion list, retained upstream conditions and derivative authorship.
- [ ] Author confirms scoped original-code license and separate documentation/figures/data/white-paper licenses. Drafts are not grants.
- [ ] Resolve contributed photograph and mixed illustrations, or exclude them from new public distribution.
- [ ] Approve the exact branch/commit and candidate asset/metadata checksum set.
- [ ] Freeze candidate; assign actual publication date and never reuse the accepted version for changed bytes.
- [ ] Author explicitly authorizes push, release creation and any Zenodo deposition.
- [ ] Configure and verify immutable-release controls, upload without replacement, re-download and verify published bytes.
- [ ] Verify the long-term record's exact files and actual version/concept identifiers, then update citation guidance in a new appropriate version if necessary.

Permission to audit or test is not permission to contact institutions. No enquiry, application, spending, publication or deposition has been made.
