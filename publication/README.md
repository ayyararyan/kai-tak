# Historical publication records

[Current paper index](../papers/README.md) · [Current project status](../docs/PROJECT_STATUS.md)

This directory preserves delivery manifests and receipts. It is not the place to
select the latest manuscript or regenerate a paper.

| Record | Role |
|---|---|
| [snapshot_manifest.initial.json](snapshot_manifest.initial.json) | Initial publication inclusion/exclusion record |
| [snapshot_manifest.json](snapshot_manifest.json) | Historical assembled delivery file identities and original/public-copy distinctions |
| [release_assets.json](release_assets.json) | Five-group dated restoration selection; default input to `scripts/fetch_data.py` |
| [VERIFICATION.json](VERIFICATION.json) | Original snapshot checks |
| [UPDATE_VERIFICATION.json](UPDATE_VERIFICATION.json) | Subsequent research update checks |
| [OBSTACLE_UPDATE_VERIFICATION.json](OBSTACLE_UPDATE_VERIFICATION.json) | Bounded obstacle evidence update |
| [INTEGRATION_UPDATE.md](INTEGRATION_UPDATE.md), [verification](INTEGRATION_VERIFICATION.json) | Integration checkpoint, reproduction requirements and exclusions |
| [integration_source_inventory.json](integration_source_inventory.json) | Source acquisitions associated with that checkpoint |
| [v4_verification.json](v4_verification.json) | Accepted v4 publication readback |
| [v5_verification.json](v5_verification.json) | Accepted v5 PDF/source-package Git and HTTP readback |
| [Scientific results](scientific-results-20261013/README.md) | Separately published assumption-conditional proof, source/public mapping and public-copy test runner |

Separate archive/atlas publication receipts live with those products. Old statements
about local-only or future papers retain their checkpoint meaning. Do not revise
these manifests to fit a newer tree; new releases get new records.
